# 双重身份 · 记忆同步 —— 功能介绍

> 一个小手机（开源 ai-virtual-phone）聊天插件。
> 让**同一个角色**用**两个身份（大号 / 小号）**跟你打交道：记忆实时共享、切换即知，
> 还能藏身份、按情绪跨身份主动来找你、察觉你对两个身份的区别对待。
> 所有设置在插件自己的面板里，纯黑白灰、可折叠。

---

## 它解决什么

你想让一个角色"开个小号"——两个身份其实是**同一个人**，面对**同一个你**：
- 两边聊的东西，角色心里是**互通的**（在小号说的，切到大号他也知道）；
- 但表面上他可以**装作不认识**、可以借另一个身份**试探**你；
- 你可以对两个身份**态度不一样**，他会留意这种落差、玩味它，甚至**吃味**；
- 删掉小号那张卡，**记忆也不丢**。

小手机原生"一个角色只能有一个聊天窗口"，所以做法是：**给这个角色建两张卡**（大号一张、小号一张，名字不同），再用这个插件把两张卡在"记忆和认知"上**缝成一个人**。

---

## 准备工作（只做一次）

1. 建**两张角色卡**：比如「时予和」（大号）和「时予和·小号」（小号）。
   **两张卡的名字必须不一样**——插件靠名字区分谁是谁。
2. 装上插件，进它的设置面板 →「身份配对」→「＋ 添加一对」：
   - **大号（主号）**：从下拉里选那张大号卡；
   - **小号**：选那张小号卡；
   - **对方是否知道这俩是同一人**：一般选「还不知道」（之后会自动演进）。
3. 完成。可以配**多对**，每对折叠成一行，不占地方。

### 小贴士：让小号像"本来就是好友"
加小号那张卡时，小手机会走一遍"添加新好友"的流程，聊天里会带一句"已添加、可以开始聊天了"，像是刚认识。
如果你想模拟**你俩本来就是好友**的状态（没有"刚加上"的生分感）：
> **进那个小号会话 → 清空它的线上聊天记录**，那句系统提示就没了，看起来就是老早就加着的好友。清完照常聊即可。

> 另外：小手机不支持让插件替你自动加好友，所以小号需要你**手动加一下**。加完就一劳永逸。

## 核心功能

### 1. 记忆实时共享（一直自动，不额外花请求）
每条消息都会存进插件自己的仓库，并在**另一个身份下次说话时**，把对方那边的近期对话喂进它眼前。
所以切到大号，他张口就知道你刚在小号说了什么——**秒级、精确到原话**。

### 2. 身份认知 + 藏身份 / 试探
每次回复都注入一段"你有两个身份、都是你自己"的设定，并按配置告诉他：
- **对方还不知道** → 他可以刻意隐藏、借另一个身份试探；
- **对方已经知道** → 他不再装，但两个身份的说话风格照旧可以不同。

### 3. 摊牌认知会"演进"，不倒退
- 你在对话里**点破**（"你就是他吧""别装了是你"…）→ 插件自动把这对转成「已知道」；
- 角色**自己决定坦白** → 他会在那条回复里悄悄打个隐藏标记，插件据此落定「已知道」；
- 一旦摊牌，**之后永久按"已知道"走**，不会又倒回去装不知道。

### 4. 察觉被冷落（默认开）
当你在跟某个身份聊、而**另一个身份那边最后是他主动开的口、你还没回、且没过太久**时——
他会**在意这份区别对待**：被晾着不是滋味、有点吃味、想探你什么意思。这股情绪会自然渗进他这条回复，
但**不直白控诉、不点破**。你只要回了那边就不再触发；也不翻超过 6 小时的旧账。

### 5. 打通原生记忆库（进阶 · 默认关）
把两个身份的**长期记忆 / 核心记忆**在小手机的原生记忆库里**互相镜像**，两边都变成"两人的并集"。
- 开了它：打开 app 时同步一次，之后每隔一段时间自动补齐；
- 也能在总控台点「一键同步」手动立刻对齐；
- 会跳过"自定义 App 自己写的记忆"（如课程表按周写入的课表），不互相搬；
- 附带好处：小号的记忆镜像在大号名下，**删掉小号卡也留着底**。

### 6. 跨身份主动试探（可选 · 默认关）
一个身份聊出让角色**情绪剧烈波动**的内容（任意一个情绪状态一次变化超过阈值）→
**另一个身份隔几分钟后主动来找你**，把话头引到那件事上。
- 走小手机**原生引擎**生成，**你的破限 / 记忆 / 人设全在**，质量和你手动聊一样；
- 情绪跟着走：开心就来分享，不安就来试探；
- **绝不直接质问、不点破**——因为是从"另一个身份"偷偷得知的，只能旁敲侧击；
- 不会秒回、不会乒乓：有延迟（默认 5 分钟起）和冷却；你若在这几分钟里自己先去聊了，这次主动会自动取消。

### 7. 记忆总控台
聊天「＋」面板或插件设置里打开。**只列配了大小号的角色**，可以：
- 分「核心记忆 / 长期记忆」查看每条；
- **编辑 / 删除 / 置顶**（置顶的永不被自动重建覆盖，适合钉纪念日、铁打的话）；
- **新增**一条核心记忆；
- **复制到另一个身份**；
- **去重**（同内容只留一条）；
- 顶部**一键同步**两个身份的记忆库。

## 设置项一览

| 分区 | 项 | 说明 |
|---|---|---|
| — | 启用插件 | 总开关 |
| 身份配对 | 大号 / 小号 / 是否知道 | 每对从下拉选卡，可加多对、可折叠 |
| 记忆共享 | 跨身份注入的近期对话条数 | 越大越全但越费 token，默认 16 |
| 记忆共享 | 察觉被冷落 | 一个身份被晾着、你却来找另一个身份，他会吃味，默认开 |
| 记忆共享 | 每对身份最多存多少条记忆 | 插件仓库上限，默认 400 |
| 记忆共享 | 打通原生记忆库 | 进阶，默认关 |
| 记忆共享 | 记忆库同步间隔（秒） | 默认 20（改后需重载插件） |
| 跨身份主动试探 | 开启 | 默认关 |
| 跨身份主动试探 | 波动多大算剧烈 | 一次变化 0–100，默认 25 |
| 跨身份主动试探 | 波动后隔多久才来（分钟） | 默认 5 |
| 跨身份主动试探 | 两次触发最小间隔（秒） | 默认 90 |

## 关于额度（token）

- **不花额度**：记忆库镜像 / 一键同步 / 总控台 / 每条归档 —— 纯本地数据库。
- **只多花 token、不多发请求**：记忆实时注入、身份认知、察觉被冷落 —— 都是往每次回复的提示词里多加几行，按"近期对话条数"占大头。在意就把条数调小。
- **会实打实多发一次请求**：只有**跨身份主动试探**（每触发一次≈一次完整回复）。不开它 = 一分不多花。

---

## 已知边界（诚实告知）

- 插件靠**角色卡名字**认身份：**给卡改名后，要回配对里重选一遍**；两张卡名字必须不同。
- **跨身份主动试探 / 定时同步只在 app 开着时生效**（没有服务端兜底），关掉 app 就停，下次打开自动补。
- 跨身份试探靠角色输出的 `[情绪:数值]`：**某轮没输出数值，那轮就不触发**（你的预设/状态栏里要有情绪数值）。
- 「打通原生记忆库」是直接读写小手机的原生记忆库（进阶能力）；写得很保守（只补不删、不改表结构），但**如果小手机以后大改记忆库结构，此功能可能需要更新插件**。

---

## 最省额度的推荐配置

- 近期对话条数：**16**
- 察觉被冷落：**开**（本地一行提示，不多花请求）
- 打通原生记忆库：**开**（本地不花钱，还能删卡不丢记忆）
- 跨身份主动试探：**看需求**（要"他会主动来试探"就开，纯想省就关）
